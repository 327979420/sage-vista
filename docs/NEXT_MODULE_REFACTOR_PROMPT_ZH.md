## 二、这次项目的不可改变总目标

最终闭环必须是：

一份点时行情与股票池
→ 一个日线MACD门卫
→ 一个共同结构与长期状态检查
→ 一个唯一候选事件
→ 复杂多因子 / 我最喜欢形态两个独立分析器
→ 大盘与行业独立上下文
→ 交易就绪判断与模拟交易计划
→ 一本不可覆盖的事件总账
→ 历史重放、机器案例与人工复盘
→ 新假设、预登记与对照实验
→ 用户批准的新版本
→ 四个网站入口
→ 线上核验后的一个Discord出口。

必须保持：

- 日线MACD是两个模型共用的事件门票；
- 机器可先用日线门票节省计算，但交易解释区分大周期确认型与小周期升级型；
- 技术、大盘、行业、人工判断和退出结果分开保存；
- 同一股票同一天只有一个事件，两个模型不能重复算两笔赢家；
- 复杂多因子是唯一主榜；我最喜欢形态是独立观察，不与主榜争权威；
- 所有MACD候选保留紧凑记录，只有达到交易标准的候选建立完整计划；
- 历史行情只保存一份，实验不能复制整盘数据；
- 网站只展示紧凑实用结果，完整研究保存在Git后台；
- Discord只读取已部署、已核验的同源结果；
- 人工可以否决机器，但不能覆盖机器当时的分数、证据、排名和时间。
