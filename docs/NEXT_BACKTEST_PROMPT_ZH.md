# 下一对话 Prompt｜评分单调性与因子归因回测

请接手 Sage Vista。先完整读取根目录 `AGENTS.md`、`docs/NEXT_SESSION_HANDOFF_ZH.md`、`docs/CURRENT_STATUS_ZH.md`、`docs/CODEBASE_MAP_ZH.md` 和 `docs/SAGE_VISTA_RULEBOOK_ZH.md`，再重点读取 `docs/rules/03_FACTOR_MODEL.md`、`04_SCORING.md`、`08_BACKTEST_AND_EXPERIMENTS.md`，以及现有评分、因子归因和回测实验。以仓库机器状态为准，不依赖旧聊天里的日期或进度。

这次目标不是马上改评分，而是先把一轮科学、可复用的回测实验定义清楚，然后经我确认再实施。我要回答三个问题：

1. 按当前这套评分，同一批合格信号中，分数越高，后续收益率、胜率、Profit Factor 和期望值是否真的越高？评分是否具有稳定的单调性，而不是只有某一小组碰巧好看？
2. 后续收益较高的股票经常共同命中哪些因子？不能只统计“赢家里出现次数最多”，还必须比较该因子在全部候选和失败样本中的基础出现率，判断它是否带来真实增量。
3. 哪些单因子、两因子组合能在开发期发现以后，继续在 2025 独立验证和 2026 前向期保持同方向？先研究单因子，再研究少量有依据的组合；不要一开始穷举所有因子的三重、四重组合。

第一轮先不要运行回测、不要改代码、不要修改生产权重。先用人话交付以下内容让我确认：

- 当前生产数据日、历史回放覆盖、下一断点、正在等待的实验，以及这次可以复用的事件池和已有结果。
- 这次实验的唯一 ID、基线、当前评分版本、股票池、样本量预期、开发 / 验证 / 前向分期和防前视口径。
- “高分”“赢家”“高收益”和“因子有效”的精确定义。建议同时报告固定持有 5 / 20 / 40 / 100 日原始收益；交易策略盈亏与原始因子收益分开，不能混成一个胜率。
- 评分单调性怎么测：报告每个分值和预先冻结的分数组，而不是跑完以后临时挑最漂亮的门槛；同时报告样本数、中位数、去极值均值、胜率、PF、期望、MFE、MAE和成本敏感度。
- 单因子怎么测：在相同“日线 MACD 完整收盘金叉”事件池内比较因子命中与未命中；附加因子必须服从父条件；高度相关因子按家族去重。除原始命中率外，要报告胜率提升、收益提升、赢家富集率及跨时期稳定性。
- 组合怎么测：只从开发期达到最低样本和增量要求的少量因子中冻结候选，再测试两因子组合；验证期不能重新挑组合。说明怎样控制小样本、重叠信号、极端值和多重比较造成的假阳性。
- 行业和大盘先作为独立分层结果，不能混进技术因子主实验后再说是技术评分有效。可以在技术结论完成后，另外比较加入行业 / 大盘上下文是否产生增量。
- 明确哪些旧数据和缓存能够直接复用。日线 MACD 门票、股票池、价格定义没有变化时，不得从零重新扫描所有股票；按自然周保存，失败不移动断点，中断从最后成功周继续。
- 分阶段执行计划和网站交付：最终必须在“历史与实验”中用人话显示做了什么、覆盖多少、哪些因子 / 组合可继续观察、哪些不成立，以及我现在能怎么用。全部原始结果、失败结果和版本永久留档。

科学底线：只用当时已完整收盘的数据，信号后最早下一交易日复权开盘进入；开发期用于发现，2025 只验证，2026 只前向观察；没有跨时期稳定、成本后仍为正且样本足够的结果，不得升级生产评分。旧事件和旧分数不得被新模型静默覆盖。

第一轮最后请给我一个简洁的实验方案和你需要我确认的少量关键选择。等我确认后，再先更新规则与预登记，然后实施、逐周保存、测试、提交、上线并返回生产网站。
