# SV 买入系统：月线主导、不出形态不做

版本：`0.1.0`（草案，research-only）
最后更新：2026-10-11
状态：用户已确认方向与五关结构（2026-10-11）；参数为暂定值，由实验决定。不进入生产评分、排名、交易规则、数据或网站。

## 一句话

**先由月线定方向，再在周线或日线等一个像样的入场位置；五关必须全部通过才买，宁可出手少，也要每一笔都像用户自己会做的那样。**

多因子不废弃：它是五关的零件、每天扫描的地基，也是五关之后的第二层（排序、过滤、仓位、风控）。

## 为什么要改

- E7b：按现有SV信号交易，9项比较无一胜过同规则随机；所有做法Sharpe低于同等投入的SPY。
- 2026-10-11盲评（案例台账第十六节）：机器把12个随机抽出的信号全部报成机会，用户只认可3个（全是月线机会），机器分数与用户分数几乎无关（排序相关0.39）。
- 根因：机器把“几个低点＋MACD金叉”当门票，再把勾选清单命中数加成分数；不看月线方向、不看是否同步、不看是否买晚，止损也不在结构位置。

## 第一层：五关

所有判断只用**已收完**的月K、周K、日K；趋势线、高低点用已经由右侧K线确认的摆动点。价格用统一复权行情；用户看盘软件多为未复权价，数值会有差别。

### 第①关：月线背景（定方向，二选一）

**A｜长期上涨中的回调**（COLB 2019、DVN 2012、EIX 2021、PG 2026、HUBB）

- 长期向上：月线EMA50在EMA200之上且EMA200向上（EMA200“在下面保驾护航”）；价格没有收盘跌破EMA200。
- 真的有回调：从最近一个月线波段高点至少回落15%，或回调触及月线EMA20／EMA50、Golden Pocket（前一段上涨的0.5—0.7回撤）。只是贴着EMA20慢涨、没有回调的不算（SHEL、HUBB“不如买SPY”）。
- 数据注意：月线EMA200要约17年数据。现有20年数据集从2004年开始，2021年以前的月线EMA200都不准。回测前须重建从上市日起的长历史数据集；历史不足200个月的股票改用“月线EMA50向上＋周线30周均线向上（Weinstein第二阶段）”并标注“EMA200不可用”。

**B｜筑底完成后启动**（TT 2009、DVN 2012—2013、AVTR 2023、AXSM 2022、BABA 2025、XTIUSD 2025）

- 前面是下跌：有一条经过至少两个月线波段高点的下降趋势线。
- 底已经出来：二选一——
  - 第二个底：两个已确认的月线低点，第二个底不低于第一个底减容差（容差取3%与0.5倍月线ATR中较大者）；第二个底出现十字星或看涨吞噬，下一根月K收阳跟随（DVN 2012-12十字星、2013-01阳线；TT 2009-03）。
  - 压缩突破：沿下降趋势线有3—4推（高点越来越低），低点持平或抬高，然后突破（DVN 2011—2013、XTIUSD四推）。
- 月线低点不再创新低。
- 底部被多次验证（踩了好几次都没破）记为加分，不是门槛（XTIUSD、POWL）。

### 第②关：形态与同步（在机会所在的级别上判断）

- **趋势线**：经过至少两个已确认的下降高点；完整K线收盘高于趋势线投影1%算突破（沿用V3定义）；突破后回踩到`max(2%, 0.5 ATR)`容差带内并收回算回踩。
- **同步**：突破那根K线前后3根之内MACD金叉，或突破时“准备金叉”（柱子为负、连续至少3根变短、已过最深一根），算同步。
  - 金叉晚4—6根：算“金叉慢”，扣分不否决（BABA周线晚6周）。
  - 突破后6根内都没金叉：不同步，不买（EIX月线）。
- 周线和月线金叉前后脚出现：加分（XTIUSD、PG）。
- 突破K线成交量是否高于20根平均（Weinstein）：先只记录、拆分观察，不当门槛。

### 第③关：入场位置（周线或日线，在月线方向之内）

月线过关后**6个月内**有效；收盘跌破第一个底（或A类的结构低点）即作废。只在这个窗口里找下面任一入场点：

| 入场点 | 定义 | 例子 |
|---|---|---|
| T1 突破后第一次回踩 | 突破后**先真的回调一次**，回踩趋势线、颈线、EMA20／EMA50、Golden Pocket或Bullish FVG，在容差带内收回；同一次突破不能算两次（ADBE“先转变、再重置、再启动”） | PG 2026-03、TT 2009-08、BABA周线EMA50、DVN 2013-07/08 |
| T2 吞噬加跟随 | 看涨吞噬（比实体）后下一根收盘更高；或连续两个吞噬 | HUBB周线、AVTR 2023-11 |
| T3 确认阳线一半 | 吞噬或大实体阳线（实体≥1倍ATR）之后，回调到这根阳线实体的50%挂单买 | AVTR 24.27、COLB 约24 |
| T4 均线密集后启动 | 周线EMA20／50／200相差不超过2%（或1倍ATR）之后，一根K线收在三条线之上，且同周MACD金叉 | PG本周、EIX 2021-10 |

**成交方式**（Elder、Raschke）：T1、T2、T4在触发K线之后，价格高于触发K线最高价才买（突破买入单），3根K线内没成交就取消；T3用50%位置的限价单。

### 第④关：一票否决（任何一条成立就不买）

| 否决 | 定义 | 例子 |
|---|---|---|
| 月线还在下跌 | 最近一个月线低点低于前一个，且没有第二个底；或月线MACD柱还在变长（没拐头） | YPF、ECHO |
| 暴跌后没筑底 | 沿用E7b深跌规则（5年内跌超70%、没收回0.618、没筑底一年）；**例外**：B类已完成（双底＋大阳线跟随＋MACD拐头）的长期上涨中深回调可以放行 | MRNA、BTDR被拒；TT放行 |
| 长期横盘、底部做太久 | 沿用E7b宽幅箱体规则（区间≥2倍、至少来回两次） | RIOT |
| 追高 | 入场级别收盘高于EMA20超过2倍ATR；或入场前连涨3根以上；或月线连涨5根以上 | MGY、DLR、ZBH |
| 位置不对 | 在一个箱体里，价格位于箱体中间以上（只在下沿买） | SHEL、ECHO |
| 动能在减弱 | 入场级别MACD红柱连续2根缩短，或快线正在下穿慢线（“准备死叉”） | MGY、DVN、EIX周线 |
| 前面有看跌信号没收回 | 最近3根内有看跌吞噬或大阴线（实体≥1.5倍ATR），价格没收回它的开盘价；除非之后已在下一个支撑完成T1回踩 | QTWO、YPF、BOTT |
| 卖压 | 多轮看跌吞噬／大阴线（E7b `bearish_pressure`）；上方多重顶离入场不到1.5R | TTD、AEVA |
| EMA50失守没修复 | 入场级别收盘跌破EMA50后还没重新站上 | AEVA、POWL |

“K线重叠越来越多”（DLR）先作为风险标记记录，不当否决。

### 第⑤关：先算好止损、止盈和盈亏比

- **止损**：下方最近的结构位置再往下一点——第二个底、回踩低点、触发K线低点或第一个底，缓冲取1%与0.25倍ATR中较大者；周线EMA100可作参考支撑（BOTT）。不用“入场价往下固定百分比”。
- **止盈（第一目标）**：上方最近的一个——前高（趋势线起点或颈线所在高点）、未回补的看跌FVG下沿、下跌段的0.618、上方成交密集区（120日价值区）。
- **盈亏比**：到第一目标的空间至少是止损距离的1.5倍才买，2倍以上优先（09规则）。FVG既是目标也是上方卖压：离得太近、凑不够1.5R就不做。
- **仓位**：打到止损最多亏账户2%，单只不超过5%，同时最多10只，总风险不超过20%（沿用E7b）。
- **离场**（实验只登记两种）：X1 到第一目标全部卖出；X2 到第一目标后止损移到成本，再按最高收盘价下方8%跟踪（20年审计：胜率更高）。最长持有暂定：月线级12个月、周线级26周、日线级60个交易日。

## 第二层：多因子怎样用（不浪费）

| 用法 | 内容 |
|---|---|
| 零件 | 五关里的EMA距离、斐波那契与Golden Pocket、双底／三底／W底颈线回踩、三推趋势线、MACD状态、FVG、卖压标记，都来自现有因子与E7b结构检查 |
| 地基 | 每天扫描约1,500只美股、只用当时可见数据、20年回放与账本，全部沿用 |
| 排序与过滤（元标签思路） | 五关都通过的信号，按多因子分数、相对强度（对SPY和行业，6个月）、回调缩量、多周期支撑共振（PPG）排先后；高分是否真的更好，由实验判断 |
| 风控 | 大盘过滤（SPY在200日均线上才开新仓）、行业环境调整仓位 |

机器学习式的第二层（López de Prado的元标签）要等五关信号累计到足够多（暂定500个以上）再考虑，避免样本太少学出巧合。

## 每个买点必须附的依据卡

股票／级别／信号日；月线背景（A或B，用了哪条EMA、回调多深）；趋势线两点（或几推）的日期和价格；两个底的日期和价格；突破日、MACD金叉日与是否同步；入场点类型（T1—T4）和触发K线；被检查过的否决项（全部写“未触发”或触发原因）；止损、第一目标及其来源、盈亏比；第二层分数与大盘状态。

机器状态分档：`早期发现`（只过了①）→`月线过关·等入场`（过了①②，在6个月窗口里）→`入场就绪`（五关全过）；以及`风险否决`、`失效`（跌破第一个底或窗口过期）。

## 验证顺序（全部预先登记，后台运行）

1. **工程检查**：在冻结数据上跑用户标过的案例。用户判“没有”的7个（MGY、HUBB、SHEL、ZBH、DLR、QTWO、DVN 2012-04）必须被拒；用户指出的买点（TT 2009、AVTR 2023—2024、COLB 2019-05、DVN 2013、AXSM 2022-10、BABA 2025-07）附近必须出现信号。只修定义错误，不按结果调参，每次修改留档。
2. **反向盲评**：从20年信号里随机抽10个给用户评，用户认可至少8个才算过关；同时给用户看5个“漏掉的大涨股”和5个“差一点通过的”。
3. **20年检验**：对同一天、同股票池、同止损距离（按ATR倍数）与同目标倍数的随机股票，以及同等投入的SPY；三个版本——A 只用五关、B 五关＋多因子排序、C 五关＋大盘过滤；离场X1、X2。报告胜率、盈亏比、Sharpe、最大回撤、笔数。20年里笔数不足100时如实报告“样本不足”。
4. **前向观察**：PG（2026-10，周线机会）记录之后走势；BOTT不在数据中，只作形态参考。
