# Sage Vista 个人交易系统

版本：`2.0.0`
最后更新：2026-08-30

## 这套系统在找什么

这个独立页面现在故意做得比复杂多因子简单。它不负责把三十多个因子都解释一遍，只找用户最愿意人工看的日线形态。

一句人话：**先有一段回调，回调落到Golden Pocket或EMA20/50/200附近，形成双底，再完成三推下降趋势线的收盘突破。四件事齐了就优先人工看。**

这套个人形态与复杂多因子排行并列观察，不要求当天MACD刚金叉，不改变多因子门票、仓位、止损、退出或通知。旧V1静态七项和V2两段七阶段继续留档，不覆盖原信号。

## 简化V3的四项

1. **客观回调**：第一底前60个完整交易日最高价到两底较低价至少回落5%。
2. **宽口径双底**：两底由右侧K线确认，相隔15—120个交易日，价格差和中间反弹满足冻结容差。
3. **三推突破**：三个已确认下降高点形成趋势线，之后完整日K第一次收盘突破投影趋势线1%。
4. **位置承接**：较低底落在前段波段50%—70%回撤，或任一底距离当日EMA20、EMA50、EMA200不超过6%。

`4/4`只表示形态完整。多轮看跌压力、顶部供给或结构失效继续单独否决；机器必须告诉用户命中了哪条EMA、距离多少、两底日期和突破日期。

## 举一反三原则

- 案例教的是判断职责与发生顺序，不是固定图形。ADBE不要求别的股票拥有同样日期、同样两组W底或同样EMA交叉；BABA也不要求所有机会都先有长期上涨。
- V3机器先回答四个形态问题；旧V2的七个机制问题继续作为人工解释和只读对照，不再成为V3入选门槛。同一机制允许由不同证据路径完成。
- 双底、三底、趋势线三推、颈线回踩、EMA50动态支撑和FVG守住是可能的实现路径，不互相冒充，也不要求每只股票全部出现。
- 正式信号与近似观察严格分开。近似机会必须逐项写明“已完成什么、还缺什么、被什么风险阻断”，它帮助人工发现漏检，不产生自动买入、加分或新账本交易。
- 单案例只能校正描述或提出后验候选；只有跨股票、跨时期对照和冻结后的前向样本支持，才能建立新版本或讨论权重。

## 五层判断顺序

1. **背景**：前面确实出现过一段可量化上涨，或从长期弱势中形成了清楚的日线趋势转变。长期趋势不是个人形态的硬门票；ADBE正是“长期不强、日线先转强”的定义案例。
2. **位置**：回调应落到能解释的位置，例如Golden Pocket、EMA200／EMA50动态支撑、已突破颈线、Bullish FVG或前一结构支撑。位置证据分别保存，不能互相冒充，也不能因为同一故事重复加分。
3. **第一段结构确认**：已确认的双底／三底与三推下降趋势线相互印证，完整日K收盘突破；底部附近MACD转多，EMA20／50从空头关系转为改善或多头排列。
4. **真实重置后的二次确认**：第一段完成后必须出现新的回调、动能重置和新的pivot，不能把同一段突破连续几天重复算两次。新的W底／回踩守住后，再由收盘突破、MACD重启和EMA转强确认。
5. **风险否决**：上方多重顶、未回补Bearish FVG、多轮看跌吞没／大阴线卖压、EMA50失守而未修复，都会降低或否决做多优先级。正面条件多不代表可以忽略供给。

## EMA在系统里的职责

- EMA50是动态承接和结构是否仍在的参考。一次触碰不够；要记录触碰次数、反弹分隔、是否收盘跌破及是否重新收复。
- EMA20是短期强弱和追高程度。价格站在EMA20上且EMA20上升，代表买方仍强；跌破EMA20但守住EMA50通常是盘整；EMA50也失守则原支撑故事需要重新审查。
- 第二次确认不强求所有均线在同一天完美排列。允许“价格先收复EMA20／50、EMA20转升并向EMA50收敛”，随后再升级为`EMA20 > EMA50`的完整多头排列；两个时点必须分别留档。

## 教学案例之一：ADBE 2023

- 第一段：2023-02-24与03-13附近形成日线双底；2月至3月出现下降高点的三推／四推结构；03-16附近出现趋势线与MACD修复，03-21附近EMA20／50完成趋势转变，03-30再出现完整突破确认。
- 重置：4月底至5月初重新回调，05-04与05-12形成新的局部W底，说明这不是把3月同一结构重复计数。
- 第二段：05-17收盘突破局部颈线，05-18日线MACD金叉；截至05-18，价格已收复EMA20和EMA50、EMA20重新转升并向EMA50收敛，形成“二次启动”；05-25 EMA20正式上穿EMA50是后续完整排列升级，不应把最早观察拖到6月。
- 结果只作案例描述：按档案05-18信号、05-19次日开盘口径，5/10/20/40/60日原始收益约为`+8.0%/+20.2%/+36.4%/+46.6%/+42.9%`。ADBE教“先转变、再重置、再确认”的顺序，不是所有机会必须复制的标准外形，也不是独立胜率证明。

## 固定反例

- **TTD 2025-01**：虽然有MACD、回调、FVG等正面证据，但此前已有多轮看跌吞没／大阴线卖压、EMA20／50反复失守和未回补Bearish FVG。个人系统必须显示风险未修复，不能仅凭底部形状升级。
- **AEVA 2026-07**：信号前已有多重顶部供给、6月15日顶部Doji后的严格看跌吞没和跟随；7月1日本身又是墓碑型Doji。个人系统必须拒绝把它标成完整多头二次确认。
- **PG**：归入V1旧系统历史观察。旧数据和旧结论保留，但不再作为V2个人形态的定义或参考卡。

## 机器状态与使用边界

- `早期发现`：只命中1—2项。
- `等待突破／等待位置`：已经命中3项，明确显示缺少哪一项。
- `形态完整`：4/4且风险闸门清除，进入人工复核并按新版本建立前向观察。
- `风险否决／失效`：4/4但空头供给未修复，或收盘破坏结构时，不建立可行动事件。

颗数只说明四个形态条件完成了多少，不代表胜率。ADBE、BABA、TTD和AEVA都已经看过，不能证明V3收益；V3收益只能从规则冻结后的新事件产生。旧V2仍可在Git中研究“二次确认是否额外有用”，但不再作为此页面的主门槛。

## 每次人工复盘怎样继续教系统

1. 记录股票、点时日期、当时可见K线和用户判断，不使用后续走势补写当时证据。
2. 区分“位置、结构、动能、趋势、供给、退出”家族，先检查是否已存在同义因子。
3. 写明机器原判断、人工不同意的具体原因，以及成功识别或误判的验收条件。
4. 单案例只更新案例库或提出候选定义；要改权重，必须另做命中／未命中和收益对照。
5. 每次完成实验都交付赢家、输家和边界案例，供人工逐根K线复查。
6. 固定增加“漏检赢家、误收输家、接近但未完成”三类复盘；人工指出的差异先记录成机制缺口，不直接改当前版本。
