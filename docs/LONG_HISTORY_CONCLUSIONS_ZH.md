# 2000—2026 MACD因子长期回测结论

最后更新：2026-08-29

## 一句话结论

日线MACD金叉可以继续作为事件门票，但三十个可对照技术因子中，没有任何一个达到“跨开发期、2025独立验证和2026前向期均稳定，可无条件提高正式权重”的A级标准。当前最实用的做法是减少无效重复加分，优先观察底部放量和底部看涨吞没，并把移动止损视为控制盈利回吐的工具，而不是提高长期期望的确定答案。

## 覆盖和方法

- 2000年是420日历史预热期；有效研究为2001—2024开发、2025独立验证、2026前向观察。
- 历史共6,539个交易日、57,271个全部候选、1,379个自然周检查点；每周明细和年度压缩包留在GitHub，不进入网站。
- 事件门票始终是完成收盘的日线MACD刚金叉；技术因子命中与同一候选池未命中比较。
- 大盘和行业没有混入技术分归因，只能另作分层。
- 少量原始平均收益受公司行动或数据极值污染，因此定级主要依据年度胜率增量和中位收益增量；不把异常均值包装成有效因子。

## 因子怎么处理

| 层级 | 因子 | 证据 | 当前处理 |
|---|---|---|---|
| A | 无 | 没有单因子通过全部时期 | 不提高任何正式权重 |
| B | 底部放量 | 开发期18个可评年份中12年胜率和中位数同时改善；2025近中性；2026胜率增量+5.88个百分点 | 优先观察，暂不加正式权重 |
| B | 底部看涨吞没 | 开发期6年中4年双正；2025胜率增量+2.74；2026 +1.68 | 保留为支撑确认，不单独触发 |
| B | 上方未补跳空缺口 | 稳健胜率与中位数长期偏正，但2026原始均值方向冲突 | 候选取消风险扣分；先不直接加分 |
| B | 支撑位看涨吞没、三推突破、周线MACD柱改善 | 2025和2026方向偏正，长期混合 | 继续影子观察 |
| C | EMA、斐波那契、筹码密集、Volume Profile、FVG、十字星等 | 在部分阶段有效，2025或其他阶段反转 | 只作位置/背景证据，不固定加分 |
| D | 双底、更高低点、相对放量、周线吞没、周线双吞没 | 长期或2025/2026明显偏弱 | 停止加权，只保留审计记录 |

完整30因子和五年分段数据见 `research/backtest/output/long-history-v1.json`。

## 固定止损和8%移动止损

| 时期 | 固定止损：胜率 / 平均每笔 / PF* | 8%移动止损：胜率 / 平均每笔 / PF* | 判断 |
|---|---|---|---|
| 2001—2024 | 47.64% / +0.875% / 1.292 | 48.87% / +0.792% / 1.287 | 移动止损提高胜率和中位数，但略降平均收益与PF |
| 2025 | 44.77% / +0.890% / 1.235 | 46.06% / +0.807% / 1.227 | 同样是风险更平滑、收益略低 |
| 2026 | 38.86% / +0.016% / 1.003 | 43.22% / +0.228% / 1.056 | 2026移动止损全面胜出 |

`*` 2001—2025的PF为年度PF的样本加权描述，不是重叠交易资金曲线的精确组合PF。

当前可执行解释：达到原始+1R后，从下一交易日起按此前最高完成收盘价下方8%追踪，能够减少盈利回吐并提高胜率；但长期平均收益没有优于固定止损，所以不能宣称它无条件更赚钱。若采用，应把它定义为风险偏好选择，并继续前向分账追踪。
