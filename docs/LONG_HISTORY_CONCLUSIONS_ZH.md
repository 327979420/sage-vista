# 2001—2026 完整MACD候选池审计结论

最后更新：2026-08-29

## 一句话结论

长期趋势＋完整日线MACD刚金叉可以继续作为共同事件门票：120交易日去重后的20日原始持有在开发期、2025独立验证和2026前向期均为正。但当前分、周期等权和V3都没有形成跨期单调性；31个附加因子零个验证通过，三个冻结两因子组合也没有升级。因此不能再把“底部放量、底部吞没或更高分”写成已证明更有效；生产正式权重保持不变。

## 覆盖和方法

- 2000年只作历史预热；有效研究为2001—2024开发、2025独立验证、2026前向观察。
- 复用63,817个来源候选；排除1,615个缺少可核对价格的早期事件和32个不能在审计复权序列中重现门票的事件后，保留62,170个审计事件。
- 主分析按每只股票120个交易日只保留首个事件，共13,296个主样本；全部重叠事件只作敏感度分析。
- 共保存1,414个自然周检查点和27份年度摘要；网站只显示精简结论，逐周与年度证据继续留在GitHub。
- 事件门票始终是完成收盘的日线MACD刚金叉；技术因子命中与同一候选池未命中比较。
- 大盘和行业没有混入技术分归因，只能另作分层。
- 单因子主窗口冻结为20个交易日，同时检查中位数、1%去极值均值、PF、期望、20/50bps成本、BH多重比较和开发 / 验证 / 前向一致性。

## 因子怎么处理

| 象限 | 数量 | 含义 | 当前处理 |
|---|---:|---|---|
| 正在使用 | 7 | 2个共同门票；另有5个当前影子同分项，但这5个最新均判定为不稳定 | 门票继续使用；影子项正式分仍为0，不冒充有效因子 |
| 候选观察 | 13 | 样本不足、尚未完成可比归因，或只在高收益尾部富集 | 继续记录，正式权重0；相对放量和60日回撤只作尾部标签 |
| 暂停加权 | 9 | 三段收益增量方向不一致 | 仅保留位置和审计证据，不参与加权 |
| 准备弃用 | 8 | 旧登记已拒绝、证据重复或最新仍未证明稳定增量 | 保持0权重；保留历史，完成迁移后再决定是否停止日常检测 |

因子库当前共39项；其中原37项的完整四象限与历史审计见 `public/factor-effectiveness.json` 和 `research/backtest/output/score-timeframe-attribution-v2.json`，新增三底与W颈线回踩只列为候选观察、尚无历史有效性结论。完整周线MACD刚金叉是研究专用因子，20日主样本只有开发65 / 2025年10 / 2026年8，不进入生产因子库。

## 固定止损和8%移动止损

| 时期 | 固定止损：胜率 / 平均每笔 / PF* | 8%移动止损：胜率 / 平均每笔 / PF* | 判断 |
|---|---|---|---|
| 2001—2024 | 47.64% / +0.875% / 1.292 | 48.87% / +0.792% / 1.287 | 移动止损提高胜率和中位数，但略降平均收益与PF |
| 2025 | 44.77% / +0.890% / 1.235 | 46.06% / +0.807% / 1.227 | 同样是风险更平滑、收益略低 |
| 2026 | 38.86% / +0.016% / 1.003 | 43.22% / +0.228% / 1.056 | 2026移动止损全面胜出 |

`*` 2001—2025的PF为年度PF的样本加权描述，不是重叠交易资金曲线的精确组合PF。

当前可执行解释：达到原始+1R后，从下一交易日起按此前最高完成收盘价下方8%追踪，能够减少盈利回吐并提高胜率；但长期平均收益没有优于固定止损，所以不能宣称它无条件更赚钱。若采用，应把它定义为风险偏好选择，并继续前向分账追踪。

## 下一步

- 生产评分暂不因本次研究自动改变。
- 当前5个影子同分项继续前向分账；如要移除或改权重，另立冻结对照，不静默重写旧事件。
- 不再穷举组合；三个预登记两因子组合已全部样本不足，只有新增独立样本后才复核。
- 看跌吞没、RSI顶背离和MACD柱转弱等提前退出仍未启用，必须在当前固定/移动止损基准上逐项对照。
- 前向排行榜和稀有机会继续永久追踪；历史回测与真实前向结果分账展示。
