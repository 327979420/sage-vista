# 02｜数据与每日扫描规则

版本：`1.5.0`
最后更新：2026-08-30

## 本文件负责

权威交易日、扫描股票池、MACD 触发、深度检测顺序、防前视与发布前数据校验。

## 当前扫描流程

完整美股收盘数据 → 数据审计 → 一次轻量生成日线MACD当日金叉门票池 → 一次共同回撤结构预检 → 两种产品只在结构可行池内分支深查 → 保存紧凑当日快照与历史事件。

- 日线 MACD 是降低计算量、统一事件起点和寻找择时的“门票”。
- 它不是“只测试 MACD”，也不单独构成买入结论。
- 即使大盘不适合交易，技术扫描仍运行并保存事实。
- 每日全市场层只允许做数据完整性、基础流动性和精确MACD金叉等轻量门票判断；复杂因子、形态状态机、图形和旧排行不得在全市场层重复计算。
- `daily-factor-snapshot`中的触发股票集合是当日唯一门票池。门票记录按点时成交额从高到低排列；当前缺少可靠历史点时市值，因此不能把成交额排序冒充市值排序。
- 精确MACD门票后先运行一次共同回撤结构预检；复杂多因子和个人形态都只接收结构可行池。两者可以因后续资格不同而产生不同成品，但不得拥有第二套MACD候选或结构生成器。

## 共同回撤结构预检

- 点时寻找最近252个完整交易日内、至少已有两根右侧K确认的前段swing high；其前方寻找形成这段上涨的已完成低点。随后最低价是当前回调swing low。
- `retracement_ratio = (swing_high - pullback_swing_low) / (swing_high - prior_swing_low)`；0.618和0.70都作用于这段上涨，不是“股价从高点下跌61.8%／70%”。
- `retracement_ratio > 0.70`且最新完整收盘仍低于0.618回撤价位：`structure_broken`，保留门票与排除证据，但不运行39项因子或四项个人形态。
- `retracement_ratio > 0.70`但最新收盘重新站回0.618：`deep_sweep_reclaimed`，允许进入分支但必须显示深插风险。0.618—0.70记为`deep_pullback_warning`，不自动加分。
- 找不到可复现前段上涨时记`structure_unavailable`并停止分支深查；不能为了增加候选临时改pivot或窗口。

## 历史股票池五层

1. 核心池：用户核心观察名单及有点时成员证据的主要指数／高流动性标的。
2. 主扫描池：当时满足正式价格、成交额和数据完整性门槛的普通股。
3. 拓展池：主池以外但仍有可靠完整日K和公司行动处理的活跃普通股。
4. 更小股票池：低成交额、小盘／微盘候选，独立报告滑点、停牌和可交易性，不能混入主池结论。
5. 退市／将退市池：有点时退市状态、最后交易日和可复核价格路径的股票；只用于历史失败、幸存者偏差和风险研究，不进入今日排行榜。

每层按此顺序独立保存覆盖、缺失、门票数、结构排除数和后续样本。没有点时市值或退市成员数据时必须标不可用，不能用今天的名单回填历史。

## “我最喜欢形态”独立日更扫描

- 主多因子扫描继续以“完整日线 MACD 当日刚金叉”为事件门票；本页不得改变这条门票或生产候选分。
- “我最喜欢形态”是独立的简化形态检查，不是第二套生产排行榜。V3.1只读取当日唯一MACD门票池，并回答四件事：是否有客观回调、是否形成宽口径双底、是否完成三推下降趋势线的完整收盘突破、两底是否至少一次落在Golden Pocket或EMA20/50/200容差带。
- V3不要求七阶段、第二次重置、MACD再次金叉或EMA20正式上穿EMA50；这些旧V2字段继续只读保存作解释与新旧对照，不再决定V3形态是否完整。
- V3.0曾允许非MACD金叉日进入观察；该全活跃池校准结果冻结为只读旧版本。V3.1起正式候选、近似候选和风险阻断候选都必须属于同日精确MACD门票池。
- 本扫描不强制股票在形态开始前已经满足长期上涨资格；BABA与ADBE只教位置、结构和突破语言，不能为迎合案例修改阈值。
- 形成中和等待突破只进入当日观察表；只有完整日 K 收盘后达到`entry_ready`，才按下一交易日复权开盘口径进入永久前向账本。历史图片和人工画线只用于解释，不得作为机器事实输入。

## 数据纪律

- 所有生产 JSON 使用同一个已经完整收盘的美国交易日。
- 历史计算只能读取 `as_of` 当日及以前的数据。
- 周线和月线只能使用已经完整收盘的 K 线。
- 确认型 pivot 必须等待规定的右侧确认。
- 复权、股票池、退市股票、流动性门槛与数据源都要版本化。
- 数据缺失、日期错位、未来数据或关键覆盖率不足时停止发布。

## 缓存与复用

- MACD 触发事件池按日期保存，可供新增“触发后附加因子”重复研究。
- 仅新增触发后因子时，不应重扫所有股票全部历史。
- 触发器、股票池、价格调整、数据源或权威交易日定义改变时，才重建受影响的事件池。

## 输出契约

每个事件至少保存：股票、触发日期、信号收盘价、数据版本、扫描版本、完整因子状态、缺失原因和生成时间。
