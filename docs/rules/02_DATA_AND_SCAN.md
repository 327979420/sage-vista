# 02｜数据与每日扫描规则

版本：`1.1.0`
最后更新：2026-08-29

## 本文件负责

权威交易日、扫描股票池、MACD 触发、深度检测顺序、防前视与发布前数据校验。

## 当前扫描流程

完整美股收盘数据 → 数据审计 → 日线 MACD 当日金叉事件 → 按月线、周线、日线检查其余因子 → 保存当日快照与历史事件。

- 日线 MACD 是降低计算量、统一事件起点和寻找择时的“门票”。
- 它不是“只测试 MACD”，也不单独构成买入结论。
- 即使大盘不适合交易，技术扫描仍运行并保存事实。

## “我最喜欢形态”独立日更扫描

- 主多因子扫描继续以“完整日线 MACD 当日刚金叉”为事件门票；本页不得改变这条门票或生产候选分。
- “我最喜欢形态”是独立的形态状态机，不是第二套生产排行榜。它每天复用同一批完整复权日 K 和活跃股票池，识别“前段上涨 → Golden Pocket / EMA200 回调 → 宽口径双底 → 二底附近 MACD 金叉 → 三推下降趋势线 → 收盘突破 → EMA20 重新高于 EMA50”的进展。
- 因为二底金叉可能早于真正突破日，本状态机把 MACD 金叉作为二底附近的共振证据，而不是要求突破当天再次刚金叉。这个例外只属于该独立页面，不得回写主多因子门票。
- 本状态机不强制股票在形态开始前已经满足长期上涨资格；“前段有一段可测量上涨”与“长期上涨结构”分开保存。BABA 是定义案例，PG 是保留观察案例，两者都必须显示机器当前判定，不能为迎合案例而修改阈值。
- 形成中和等待突破只进入当日观察表；只有完整日 K 收盘后达到`entry_ready`，才按下一交易日复权开盘口径进入永久前向账本。历史图片和人工画线只用于解释，不得作为机器事实输入。

## 数据纪律

- 所有生产 JSON 使用同一个已经完整收盘的美国交易日。
- 历史计算只能读取 `as_of` 当日及以前的数据。
- 周线和月线只能使用已经完整收盘的 K 线。
- 确认型 pivot 必须等待规定的右侧确认。
- 复权、股票池、退市股票、流动性门槛与数据源都要版本化。
- 数据缺失、日期错位、未来数据或关键覆盖率不足时停止发布。

## 缓存与复用

- MACD 触发事件池按日期保存，可供新增“触发后附加因子”重复研究。
- 仅新增触发后因子时，不应重扫所有股票全部历史。
- 触发器、股票池、价格调整、数据源或权威交易日定义改变时，才重建受影响的事件池。

## 输出契约

每个事件至少保存：股票、触发日期、信号收盘价、数据版本、扫描版本、完整因子状态、缺失原因和生成时间。
