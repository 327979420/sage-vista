# 12｜交易红线与硬规则

版本：`1.0.0`
最后更新：2026-08-28

## 本文件负责

收录从回测、前向跟踪或真实交易亏损中确认的严格禁区。红线优先于机会分数；命中红线时，不因其他因子高分而忽略。

## 收录门槛

- 必须有可追溯证据：实验、前向事件或真实交易记录。
- 写清造成损失的机制、适用范围、机器可执行条件和例外。
- 区分“永久风险原则”与“可被新证据解除的临时禁区”。
- 新想法或单个案例先进入观察，不直接升级红线。
- 红线新增、放宽或解除都需要用户批准，并保留历史版本。

## 当前系统级硬规则

以下是研究与执行完整性的硬规则，不是未经验证的交易 alpha：

1. 不使用未来数据、未完成周线或未完成月线做历史决策。
2. 不用今天的规则重写历史事件当时的分数、排名与证据。
3. 不把未验证实验分、规则匹配分写成胜率或收益承诺。
4. 关键数据日期错位、缺失或质量闸门失败时，不发布新推荐。
5. 命中已冻结结构止损或最大风险边界时，不因高分取消风险纪律。
6. 没有客观支撑时，依赖支撑的底部形态不得独立加分。

## 待交易证据验证的禁区

当前暂无经过统一回测与批准的形态类永久禁区。后续实验和真实亏损教训必须按模板追加，不能只留在聊天中。
