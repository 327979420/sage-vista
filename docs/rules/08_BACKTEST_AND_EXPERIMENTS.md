# 08｜回测与实验规则

版本：`1.0.0`
最后更新：2026-08-28

## 本文件负责

实验怎样提出、运行、续跑、判断、留档和转化为可用规则。目标是每次实验都产生可复用证据，不白做。

## 实验生命周期

问题 → 预登记 → 基线与唯一改动 → 分块运行 → 独立验证 → 前向跟踪 → 人话结论 → 永久归档 → 进入策略宝典、交易红线或继续观察。

## 运行前必须预登记

每个实验写清：

- 唯一 ID、规则 / 代码 / 数据版本、日期和负责人；
- 研究问题、精确机器定义、父子依赖和冗余处理；
- 股票池、退市处理、流动性门槛和数据范围；
- 触发器、基线、唯一改变项和对照组；
- 开发期、独立验证期与前向观察期；
- 入场、止损、止盈、最长持仓和同 K 线冲突口径；
- 评价窗口、交易成本敏感度、通过与不通过标准；
- 已知限制，包括幸存者偏差、样本量和历史分类缺失。

## 必须可分块、可续跑

- 长任务按自然周或明确日期块运行；每块结束立即保存配置、进度和结果。
- 中断后从最后成功日期继续，不能每次从零开始。
- 新增触发后附加因子时复用已有 MACD 事件池与缓存。
- 只有触发器、股票池、价格调整或数据定义改变时，才重建相应范围。
- 每块记录起止日、股票数、事件数、状态、代码提交与数据指纹。
- 超时只终止当前块，已完成块仍可汇总使用。

## 科学性底线

- 历史选择只读 `as_of` 及以前数据；周月线只用完整周期。
- 信号收盘确认后，最早下一可交易开盘入场。
- 同一日同时碰止损与止盈时按保守口径先算止损。
- 原始收益、固定持有、支撑止损、2R 和其他策略分别报告。
- 尽可能包含退市股票；做不到必须披露幸存者偏差。
- 至少比较无成本、20bps、50bps；不得只展示理想成交。
- 参数不能根据测试集反复挑最好看结果；需要新假设就新建实验。

## 每个实验的必交成果

- 做了什么，以及相对基线只改了什么；
- 覆盖日期、股票数、事件数、成熟样本数和数据质量；
- 胜率、平均 / 中位收益、Profit Factor、期望值、最大回撤、MFE、MAE、止损率、目标命中率；
- 开发、验证、前向三个阶段的分别表现；
- 单因子、组合及大盘 / 行业分层结果；
- 结论：`可以使用 / 候选观察 / 样本不足 / 不稳定 / 不成立`；
- 用户现在怎么用，或为何不能用；
- 限制与下一步，失败不隐藏。

## 永久留档

- 成功、失败、负结果、样本不足和中断都只追加、不删除、不覆盖。
- 机器账本：`research/experiments.jsonl`。
- 网页目录：`public/experiment-catalog.json`。
- 大文件、分块结果和日志：版本化输出或 Actions artifact。
- 每条实验保存规则版本、配置、代码提交、数据范围、断点、摘要和产物路径。
- 旧实验数据继续可读；新口径通过迁移实验追加，不重写历史。

## 结论如何进入规则

- 稳定有效且获准使用：登记到 `11_VALIDATED_PLAYBOOK.md`，再考虑升级正式评分。
- 明确危险、重复造成损失且证据充分：登记到 `12_HARD_RULES.md`。
- 样本不足或不稳定：留在实验目录，不进入宝典或红线。

## 联动条件

任何会改变筛选、分数、风险或实际结果的模块改动，都必须联动本文件中的预登记与归档流程。只改页面排版无需新实验。
