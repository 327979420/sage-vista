# 08｜回测与实验规则

版本：`1.11.0`
最后更新：2026-08-29

## 本文件负责

实验怎样提出、运行、续跑、判断、留档和转化为可用规则。目标是每次实验都产生可复用证据，不白做。

长期回放采用“自然周原始检查点＋年度压缩档案＋永久年度充分汇总”的三层留档。网站不承载逐笔历史，只在整个预注册时期完成后发布总体、五年分段、独立验证、前向观察和可执行层级。原始平均收益若被公司行动或数据极值污染，必须同时报告并优先使用胜率、中位数和分段方向，不能用异常均值晋级因子。

## 实验生命周期

问题 → 预登记 → 基线与唯一改动 → 分块运行 → 独立验证 → 前向跟踪 → 人话结论 → 永久归档 → 进入策略宝典、交易红线或继续观察。

## 完成报告必须附可人工复查的案例

- 每个完成实验除总体统计外，必须给出具体案例；没有案例审计不得只凭汇总数字宣布完成或提出升级。
- 默认至少提供2个代表赢家、2个代表输家和1个边界／反例；样本不足时列出全部并明确说明。案例必须按预先固定的规则选择，例如20日收益最高、最低及最接近中位数，不能只挑支持结论的股票。
- 每个案例至少列明：股票代码、信号日、下一交易日入场日、入场口径、主持有期及退出日、5/10/20/40/60日可用收益、20/50bps成本后结果、关键命中与缺失条件，以及为什么成功或失败的人话解释。
- 涉及止损、止盈、追踪或主动退出的实验，还必须列出止损位、目标位、实际退出日、退出原因、MFE和MAE；不适用或数据缺失必须明确写出，不能留空让人误解。
- 案例是人工审计和发现规则漏洞的工具，不是统计证明。事后从案例提出的新条件必须标为`post_hoc_hypothesis`并另行预登记，不能回写原实验结论或冒充策略升级。
- 完整案例表随实验结果永久留档；交付给用户时必须用人话展示少量代表案例，并同时说明它们是否具有代表性、是否经过独立验证。

## 运行前必须预登记

每个实验写清：

- 唯一 ID、规则 / 代码 / 数据版本、日期和负责人；
- 研究问题、精确机器定义、父子依赖和冗余处理；
- 股票池、退市处理、流动性门槛和数据范围；
- 触发器、基线、唯一改变项和对照组；
- 开发期、独立验证期与前向观察期；
- 入场、止损、止盈、最长持仓和同 K 线冲突口径；
- 评价窗口、交易成本敏感度、通过与不通过标准；
- 已知限制，包括幸存者偏差、样本量和历史分类缺失。

## 必须可分块、可续跑

- 长任务按自然周或明确日期块运行；每块结束立即保存配置、进度和结果。
- 中断后从最后成功日期继续，不能每次从零开始。
- 新增触发后附加因子时复用已有 MACD 事件池与缓存。
- 只有触发器、股票池、价格调整或数据定义改变时，才重建相应范围。
- 每块记录起止日、股票数、事件数、状态、代码提交与数据指纹。
- 超时只终止当前块，已完成块仍可汇总使用。

## 夜间历史续跑

- 夜间任务按墨尔本时间每天约 21:30（夏令时约 22:30）自动启动；只要数据 Token 可用、任务没有被人工停用，就从断点继续。
- 每晚只回放断点之前的一个自然周。当前已保存区间是 2026-05-01 至 2026-08-27，所以下一批固定为 2026-04-27 至 2026-04-30，之后继续逐周向前。
- 权威断点保存在 `automation/backtest-state.json`，给网站读取的同源进度保存在 `public/backtest-progress.json`。断点只有在周结果生成、校验、合并、全量测试和提交全部成功后才向前移动。
- 每个成功周必须先保存独立周结果，再合并入 `public/unified-v2-rankings.json` 和永久机会账本；中断后重试同一周，不从全部历史重新开始。
- 已完成日期冻结当时的模型、因子注册表和规则版本。新增因子或规则只用于尚未运行的新周；如果以后需要用新规则重算旧周，必须另开迁移实验，不能覆盖原实验。
- 缺少 Token、被人工停用或已经到达目标起点时安静跳过，不伪造进度。夜间历史任务与每日最新收盘扫描相互隔离。

## 科学性底线

- 历史选择只读 `as_of` 及以前数据；周月线只用完整周期。
- 信号收盘确认后，最早下一可交易开盘入场。
- 同一日同时碰止损与止盈时按保守口径先算止损。
- 原始收益、固定持有、支撑止损、2R 和其他策略分别报告。
- 尽可能包含退市股票；做不到必须披露幸存者偏差。
- 至少比较无成本、20bps、50bps；不得只展示理想成交。
- 参数不能根据测试集反复挑最好看结果；需要新假设就新建实验。

## 下一轮因子发现方向（approved design, not started）

- 不再以最大赢家／输家的波动速度作为主要优化目标，改为条件问题：长期上涨结构成立并触发日线MACD刚金叉时，什么样的回调深度、持续时间、量能收缩、相对强弱保持和动能修复能提高后续结果。
- ATR只用于标准化回调、止损和仓位，不作为方向性加分；MACD柱三日增强作为重新转强候选；QQQ/SPY与行业ETF保持独立环境层。
- 个股、大盘、行业分别生成“过度延伸／正常回调／深度回调／趋势破坏／修复”状态，再测试三层组合的增量。
- 先报告单项和少量预登记组合相对共同门票的胜率、中位收益、PF、成本后期望和回撤；不得用旧最大100共性代替对照组。
- 2025与2026结果已经用于既有实验，下一实验若因这些已见结果修改定义，必须把它们标为开发参考；独立验收使用新的滚动留出或未来未见样本。

- 新因子只在长期趋势资格＋完整日线MACD刚金叉后归因。三底还依赖60日回调；W颈线回踩依赖客观双底突破。行业与大盘继续单独分层。
- 三底必须对比共同门票、未命中、普通双底和单纯60日回调；W颈线回踩必须对比共同门票、未命中、单纯W底突破和三推突破后回踩，禁止父形态与子确认重复计数。
- 主指标为20日扣50bps的1%去极值平均收益；同时报告5/10/40/60日胜率、中位数、PF、期望、MFE/MAE、年度方向和样本。固定持有与止损／退出结果继续分开。
- 主样本按同股120交易日只保留首个事件；使用滚动开发留出、年度分散、最低样本和BH校正。2025与2026已被看过，只作`seen_period_recheck`。
- 完成报告必须附代表赢家、输家和边界／反例，展示三个底或颈线突破／回踩的日期与价格。没有同时胜过共同门票、未命中和父／同家族对照前，两项权重保持0。

## “我最喜欢形态”前向 Tracker V1（pre-registered, forward-only）

- 实验ID：`favorite-pattern-tracker-v1.0.0-2026-08-29`；机器定义以`03_FACTOR_MODEL.md` 1.7.0为准。BABA仅用于定义页面语言和人工参考，不参与阈值优化；PG保留为表现一般的反例观察。
- 当前先做每日点时扫描和真正未见前向留档，不立即用已看过的BABA路径宣称历史有效，也不改变生产评分、唯一多因子排行、止损或通知。
- 处理组只包含完整收盘首次达到`entry_ready`的事件；观察中的形成／等待突破不进入收益统计。入场固定为下一交易日复权开盘，主窗口20日，敏感度为5/10/40/60/100日，同时保存MFE、MAE、是否先到前高目标及是否先跌破二底失效位。
- 第一对照为同日相同流动性股票中满足“前段上涨＋回调位置＋二底MACD”但尚未完成三推突破或EMA重排者；第二对照为主多因子MACD门票事件。行业与大盘只作单独分层。
- 至少积累100个入场就绪事件、跨越6个月且不少于3种市场状态后才做第一次结论；达到门槛前页面只报告样本与个案，不报告“有效胜率”。任何后续阈值变化必须另开版本，不能回写已经冻结的前向案例。

## 因子家族收益组合实验 V1（completed, research-only）

- 实验ID：`factor-family-return-combination-v1.0.0-2026-08-29`；复用因子实验室V2的62,040个点时事件和27份年度特征档，不重建MACD门票、不重新下载行情。
- 共同门票固定为完整日线MACD刚金叉并满足归档长期趋势资格；主样本按同股票120交易日保留首个事件。行业、大盘、止损、追踪止损和主动退出不进入技术组合证明。
- 四个家族按`03_FACTOR_MODEL.md`冻结为支撑位置、可控回调、重新启动、低供应风险；同家族原始指标只贡献一个布尔状态。需要分位阈值时只能从每个滚动训练窗计算，再原样应用于紧随的测试窗。
- 搜索面固定为四个单家族及四家族的15个非空AND组合，不搜索原始37项的全部排列，不搜索三态权重或任意数值门槛。
- 主优化目标为20日扣50bps后的1%去极值平均收益；同时强制报告无成本／20bps／50bps胜率、中位数、PF和期望，5/10/40/60日只作敏感度。
- 回溯走步固定为训练截至2012→测试2013—2015、截至2015→测试2016—2018、截至2018→测试2019—2021、截至2021→测试2022—2024。每折只可用训练段挑当折收益最高的合格组合。
- 组合训练入选至少80例、三个自然年，且扣50bps后PF大于1、中位数为正、去极值收益高于共同门票；最终回溯候选在四段测试合计至少300例、至少三段相对门票收益同向、单年占比不高于30%。
- 15个组合在滚动测试汇总执行Benjamini–Hochberg；最终组合还必须在20日扣50bps去极值收益与PF上同时优于共同门票、未命中样本和每个组成单家族。若只取得最高历史收益但未过这些门槛，必须标为`historical_return_winner_only`，不得进入评分。
- 2025与2026均为`seen_period_recheck`；它们不能参与家族定义、阈值、组合选择或晋级判断。真正未见前向从2026-08-29之后开始；即使回溯全部通过，初始生产权重仍为0并需另获批准。
- 永久产物必须包含全部15个组合排行、每折训练赢家及测试结果、最终候选相对门票／未命中／单家族的对照、匹配对照、年度分散、样本与执行指标不适用说明。
- 完成覆盖为62,040个点时事件、27份年度档和13,074个120交易日去重成熟事件；开发／已见2025／已见2026分别为10,013／1,895／1,166例。
- 样本充足的历史收益冠军是“支撑位置＋可控回调”。2013—2024滚动测试合计2,556例，扣50bps后1%去极值收益`0.643%`、PF `1.192`、胜率`53.83%`，高于同期共同门票的`0.230%`、`1.082`和`51.84%`，并在四个测试段中的三段取得正增量。
- 该组合没有通过最终门槛：BH `q=0.527`，且未稳定超过组成它的每个单家族。已见2025的组合去极值收益`-0.132%`、PF `1.063`，明显低于门票的`+0.465%`和`1.213`；已见2026仅在去极值收益/PF上微幅领先，胜率、中位与期望仍落后门票。
- 最终判定`historical_return_winner_only`，生产权重0。允许把“回落到支撑且回调可控”显示为人工观察标签，但不得自动加分、扩大仓位或写入验证宝典；本实验没有改变生产模型、止损或退出。

## 因子策略实验室 V2（completed, research-only）

- 实验ID：`factor-strategy-lab-v2.0.0-2026-08-29`；复用V2完整MACD事件与历史价格缓存，不重建门票、不重新下载已有行情。
- 技术主检验计算 `research/factor-candidates-v2.json` 的 point-in-time 候选；SPY/QQQ相对强弱单独输出，历史行业成员缺失时不回填。
- 主结果仍为下一交易日开盘进入后的20日原始收益；5/10/40/60日只作周期敏感度。主样本继续每只股票120交易日内保留首个事件。
- 最大赢家第一名、第二名和前20名输出案例卡，显示现有命中、缺失因子、新候选值及其同期百分位；它们只帮助理解，不决定方向或权重。
- 配对对照以每个自然年内20日收益前10%为赢家、收益`<=0`为失败池；优先在同季度匹配，并按旧技术分、前20日动量、60日回撤、ATR14占价格的标准化距离选择最近失败样本。配对过程不得使用被检验的新因子或未来路径。
- 每个候选必须同时报告：全样本五分位、命中/未命中、赢家/失败基础率、配对差异、20/50bps结果和年度方向。连续值阈值只能在当时训练窗冻结。
- 历史采用扩展窗走步：训练截至2012→测试2013—2015、截至2015→测试2016—2018、截至2018→测试2019—2021、截至2021→测试2022—2024。候选是在2026年提出，因此这些结果标为`retrospective_walk_forward`而非真正独立验证。
- 2025与2026只作为`seen_period_recheck`；真正未见前向从2026-08-29之后的新事件开始。不得再次把2025/2026包装成独立测试集。
- 候选自动归类为`retain_for_shadow / observe / reject / sample_insufficient`。只有跨走步窗口同向、配对差异同向、BH校正通过、50bps后仍有增量且家族去重后胜出的候选，才可进入另立版本的影子权重挑战者。
- 本实验完成不自动改37因子注册表、1.3.0生产分、止损、退出、行业、大盘或通知。
- 已完成覆盖为62,040个特征事件、13,074个主去重成熟事件和1,013组匹配对照。预登记严格门槛下，新旧因子均无`retain_for_shadow`，所以本轮不给任何正向因子新增权重。
- 最大赢家案例只证明尾部共性：旧回调标签与相对放量在赢家—失败配对中分别高约4.34和3.36个百分点，但此前全样本跨期结果不稳定，仍只能作为尾部机会标签。
- 历史完成后允许生成一个明确标为`hypothesis_generation_only`的未来队列，但必须同时列出开发期、已见2025、已见2026和样本量。初始队列的Connors RSI低尾已经由后续四组实验淘汰；当前只保留Choppiness高尾权重0观察和Squeeze高尾未来影子风险权重`-1`。

## Choppiness状态机制实验（completed, research-only）

- 实验ID：`choppiness-state-mechanism-v1.0.0-2026-08-29`；复用因子实验室V2年度事件和历史价格缓存，不重建MACD门票、不重新下载已有行情。
- 主状态使用`regime.choppiness_14 >= 58.814226`及5交易日变化：`>= +3.0`为高位上升、`(-3.0,+3.0)`为高位横盘、`<= -3.0`为高位下降／释放；低于当前值阈值为中低位。3日变化和`±2.0`只作敏感度，不得替换主结果。
- 主要机制对照为高位下降／释放相对“高位上升＋高位横盘”；另报三个高位状态各自相对中低位，以及下降／释放相对上升。高位内部匹配除旧技术分、前20日收益、60日回撤、ATR14占价格和同期日期外，还必须匹配当前Choppiness水平，避免把“下降”与“本来数值更低”混为一谈。
- 主窗口20日，敏感度5/10/40/60日；报告样本、胜率、中位、1%去极值、PF、期望、20/50bps和配对收益差。五个主对照在每一时期执行BH校正。
- 2001—2024、已见2025、已见2026分别报告；因为问题与阈值由已见数据产生，三段都只是机制复核。真正未见前向从2026-08-29之后开始。
- 进入研究候选库要求：下降／释放相对高位未释放在三段的20日去极值与PF同向为正，配对差同向，开发/2025/2026处理和匹配样本至少`300/100/100`，BH `q<=0.10`，且50bps后自身期望为正。通过只登记零权重研究候选，不自动进入37项生产库或1.3.0评分。
- 若高位上升相对其他高位稳定为负，可另立风险扣分前向实验；本实验不事后反转定义或直接加负分。行业与大盘继续作为独立层，不进入技术主检验。
- 完成覆盖62,040个点时事件和13,074个120交易日去重成熟事件，3/5日变化缺失及当前值复算不一致均为0。高位下降／释放样本在开发/已见2025/已见2026仅`148/25/24`，相对高位未释放的20日去极值增量为`-0.80/-3.00/-1.17`个百分点，PF增量为`-0.315/-0.858/-0.553`；3日敏感度也跨期不一致，释放候选判定`reject`。
- 高位上升相对中低位的20日去极值增量为`+0.48/+1.81/+0.87`个百分点，PF增量为`+0.151/+0.575/+0.289`，配对收益差也同向为正，但三段BH q为`0.344/0.116/0.856`，未达到`0.10`。因此只在原Choppiness候选下保留零权重真正前向观察，不新增因子或分值。

## 评分单调性与因子归因 V1 冻结口径

- 实验 ID：`score-monotonicity-factor-attribution-v1.0.0-2026-08-29`。
- 事件门票为完整日线 MACD 刚金叉；只用事件当时冻结的技术分和因子，大盘、行业只能另表分层。
- 高分主定义为技术候选分 `>=5`；同时报告每个原始分值及冻结的 `0–2 / 3–4 / >=5` 分组。
- 原始赢家为对应固定持有窗口收益 `>0`；策略赢家为扣成本后策略盈亏 `>0`，两者不得混用。
- 高收益为每个时期和持有窗口的原始收益前 10%；同时报告绝对收益 `>=10%` 敏感度。失败对照为收益 `<=0`。
- 主分析对同一股票在最长可用窗口内只保留首个事件；全事件作为敏感度分析。
- 单因子开发期 / 2025 最低命中样本为 300 / 100；两因子组合为 200 / 75。2026 样本不足时只能标为方向观察。
- 单因子必须报告全部候选、赢家、高收益和失败样本的基础出现率，以及胜率、中位 / 去极值收益、PF 和期望增量。
- 附加因子先执行父条件；高度相关因子按家族去重。只有开发期达标且来自不同家族的因子才能进入冻结两因子组合。
- 多重比较使用 Benjamini–Hochberg 控制假发现率；不得用 2025 或 2026 重新挑因子、组合或门槛。
- 有效因子需在开发、2025 和 2026 保持同向，样本达标，且 20 / 50bps 成本后期望仍为正；否则只能归类为候选、样本不足、不稳定或不成立。
- 冻结事件池没有的逐事件窗口必须标记缺失；不得用旧聚合结果伪装成本轮逐事件结果。

## 实验时间线与中文总结
