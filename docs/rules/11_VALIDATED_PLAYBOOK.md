# 11｜有效策略宝典

版本：`1.0.0`
最后更新：2026-08-28

## 本文件负责

只收录经过开发、独立验证和前向观察后获准使用的因子组合、交易方案与适用条件。它是“目前有哪些打法真的可以用”的答案。

## 收录门槛

- 引用已完成且不可变的实验 ID、规则版本、代码提交和数据范围。
- 达到实验预登记的样本量、收益、回撤、成本和跨时期稳定性标准。
- 明确适用股票池、市场环境、周期、入场、止损、目标、持仓窗和失效条件。
- 写清怎样使用，不把历史胜率保证成未来收益。
- 经用户批准后才从候选观察升级为正式宝典条目。

## 当前已验证条目

**暂无。** 当前 V2 与新增高周期规则仍处于研究 / 前向观察阶段。旧系统表现可作为基线证据，但在完成统一口径验证前不冒充正式结论。

## 条目模板

- 策略 ID / 名称 / 版本：
- 状态：validated / retired
- 适用范围与主导周期：
- 精确组合与执行规则：
- 证据：实验 ID、样本、验证期、前向期、成本后结果：
- 用户怎样使用：
- 不适用条件与风险：
- 批准日期与原因：

## 维护规则

新证据推翻旧打法时不删除原条目，改为 `retired`，记录停止使用日期和原因。
