# 03｜因子模型与依赖规则

版本：`1.1.0`
最后更新：2026-08-28

## 本文件负责

因子身份、机器定义、周期、父子依赖、互斥 / 冗余和研究状态。不负责决定具体分值。

## 当前边界

- 因子库 `0.8.0`，共 37 个登记因子。
- 日线 MACD 为触发因子；其余因子在触发后检测。
- 注册表是机器权威：`services/scanner/factor_registry.py` 与 `public/factor-registry.json`。
- 新周线/月线 EMA、单次吞没和双吞没当前为实验因子。

## 因子层级

- 方向：长期上涨结构、月 / 周方向、MACD 改善。
- 位置：EMA、Volume Profile、K 线聚集、Fibonacci、FVG 支撑。
- 附加确认：吞没、Doji、锤头、双底、更高低点、K 线跟随、三推回踩等。
- 风险与供给：上方未补缺口、结构失效和其他风险证据。
- 上下文：大盘与行业单独保存，不冒充技术形态。

## 周期规则

- 完整月线负责长期方向、支撑与反转。
- 完整周线负责中期趋势、波段支撑与反弹力量。
- 完整日线负责触发、位置与入场择时。
- 同一机器定义扩展到新周期时必须拥有独立 ID 和明确收盘规则。

## 父子依赖

- 底部 Doji、双底、更高低点和底部类吞没依赖客观支撑背景；没有支撑时不独立成立。
- 支撑可来自当时已知的 Volume Profile、K 线聚集或已批准的其他结构。
- “看涨吞没后下一根阳线”的 K 线跟随只作为吞没附加确认，不独立触发。
- 支撑位看涨吞没覆盖原“底部看涨吞没”，不保留两个重复概念。
- 独立 Bullish FVG 被扫至约 50% 后守住，可作为独立多头力量假设，需精确定义后实验。

## 重复证据

- 同周期同家族只保留最高贡献；双吞没取代单次吞没。
- 同周期 EMA20/50/200 可全部记录，但 EMA 支撑家族只贡献一次。
- 跨周期一致可登记共振，但是否加奖金由评分实验决定并封顶。
- 三推是最低结构门槛；低点结构仍有效时，可登记 4 推、5 推强度，具体优势必须回测。

## 新登记的背离与退出因子假设

以下先进入规则与预登记，尚未升级为生产执行：

- `exit.structure.bearish_engulfing`：前一根完整日 K 收阳，当前完整日 K 收阴；当前阴线实体上沿不低于前一根阳线实体上沿，实体下沿不高于前一根阳线实体下沿。只比较实体，不要求影线吞没。
- `exit.structure.bearish_follow_through`：看跌吞没后的下一根完整日 K 继续收阴，且收盘低于吞没 K 的收盘；必须依赖前一日看跌吞没，不能独立成立。
- `exit.rsi.triple_bearish_divergence`：三个已确认价格波峰依次创新高，第一峰 RSI 处于预登记超买区，第二、第三峰 RSI 依次未创新高。信号只能在第三个波峰经过右侧 K 线确认后成立。
- `exit.macd.positive_histogram_weakening`：日线 MACD 柱仍大于零，但连续两个完整交易日缩短；这是弱动能证据，不能单独取代价格止损。
- `rsi.triple_bullish_divergence`：三个已确认价格波谷依次创新低，而相应 RSI 低点依次不再创新低。它是入场端普通 RSI 底背离的加强版，与两段底背离同属 `rsi_reversal` 冗余组；命中时取更强等级，不与普通底背离重复相加。

三峰 / 三谷背离中的波峰波谷必须使用已确认 pivot，保存每个 pivot 的日期、价格、RSI 和确认日，禁止用未来 K 线提前标记。
