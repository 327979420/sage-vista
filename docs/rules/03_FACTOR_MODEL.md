# 03｜因子模型与依赖规则

版本：`1.0.0`
最后更新：2026-08-28

## 本文件负责

因子身份、机器定义、周期、父子依赖、互斥 / 冗余和研究状态。不负责决定具体分值。

## 当前边界

- 因子库 `0.8.0`，共 37 个登记因子。
- 日线 MACD 为触发因子；其余因子在触发后检测。
- 注册表是机器权威：`services/scanner/factor_registry.py` 与 `public/factor-registry.json`。
- 新周线/月线 EMA、单次吞没和双吞没当前为实验因子。

## 因子层级

- 方向：长期上涨结构、月 / 周方向、MACD 改善。
- 位置：EMA、Volume Profile、K 线聚集、Fibonacci、FVG 支撑。
- 附加确认：吞没、Doji、锤头、双底、更高低点、K 线跟随、三推回踩等。
- 风险与供给：上方未补缺口、结构失效和其他风险证据。
- 上下文：大盘与行业单独保存，不冒充技术形态。

## 周期规则

- 完整月线负责长期方向、支撑与反转。
- 完整周线负责中期趋势、波段支撑与反弹力量。
- 完整日线负责触发、位置与入场择时。
- 同一机器定义扩展到新周期时必须拥有独立 ID 和明确收盘规则。

## 父子依赖

- 底部 Doji、双底、更高低点和底部类吞没依赖客观支撑背景；没有支撑时不独立成立。
- 支撑可来自当时已知的 Volume Profile、K 线聚集或已批准的其他结构。
- “看涨吞没后下一根阳线”的 K 线跟随只作为吞没附加确认，不独立触发。
- 支撑位看涨吞没覆盖原“底部看涨吞没”，不保留两个重复概念。
- 独立 Bullish FVG 被扫至约 50% 后守住，可作为独立多头力量假设，需精确定义后实验。

## 重复证据

- 同周期同家族只保留最高贡献；双吞没取代单次吞没。
- 同周期 EMA20/50/200 可全部记录，但 EMA 支撑家族只贡献一次。
- 跨周期一致可登记共振，但是否加奖金由评分实验决定并封顶。
- 三推是最低结构门槛；低点结构仍有效时，可登记 4 推、5 推强度，具体优势必须回测。

## 新因子最低字段

ID、中文名、定义、周期、输入字段、父条件、冗余组、事件有效期、缺失状态、研究状态、首次版本、防前视测试和解释文本。
