# 03｜因子模型与依赖规则

版本：`1.6.0`
最后更新：2026-08-29

## 本文件负责

因子身份、机器定义、周期、父子依赖、互斥 / 冗余和研究状态。不负责决定具体分值。

## 当前边界

- 因子库目标版本 `0.10.0`，共 39 个登记因子；本轮新增两项均为研究观察、正式权重0。
- 日线 MACD 为触发因子；其余因子在触发后检测。
- 注册表是机器权威：`services/scanner/factor_registry.py` 与 `public/factor-registry.json`。
- 新周线/月线 EMA、单次吞没和双吞没当前为实验因子。
- `macd.weekly_bull_cross` 是本轮回测专用的研究因子：只用信号日前最后两个完整自然周，最新完整周 MACD 线高于信号线、前一完整周不高于时成立。它暂不加入生产注册表和生产评分。
- 周线 MACD 柱改善与完整周线 MACD 刚金叉是两个不同事件，不得互相替代；现有月线金叉仍按完整月线检测。

## 因子层级

- 方向：长期上涨结构、月 / 周方向、MACD 改善。
- 位置：EMA、Volume Profile、K 线聚集、Fibonacci、FVG 支撑。
- 附加确认：吞没、Doji、锤头、双底、更高低点、K 线跟随、三推回踩等。
- 风险与供给：上方未补缺口、结构失效和其他风险证据。
- 上下文：大盘与行业单独保存，不冒充技术形态。

## 因子家族职责层（research-only）

- 为避免37项指标重复计分，组合研究先把技术证据压缩成四个职责家族：`support_location`支撑位置、`controlled_pullback`可控回调、`reacceleration`重新启动、`low_supply_risk`低供应风险。
- `support_location`合并日／周／月EMA、Fibonacci、Golden Pocket、K线聚集、Volume Profile代理和Bullish FVG等位置证据；任意多项同时命中也只算一个家族状态。
- `controlled_pullback`要求已有60日回调，并由回调深度、距高点时间、Ulcer下行伤害和20日涨跌力量中至少两项确认“不是浅到没回调，也不是深到趋势破坏”。阈值只能用每个训练窗冻结的分位数。
- `reacceleration`由MACD柱三日增强、相对量、ADX/DI方向控制、信号K收盘位置，以及已登记的放量／吞没／突破确认中至少两项构成；日线MACD金叉本身仍是门票，不能在此重复得分。
- `low_supply_risk`由没有上方未补缺口、CMF不为负、价量变化相关不为负、Squeeze不过度扩张和Ulcer不处于高尾中的至少三项构成；它首先是风险过滤家族，不自动等同于正向Alpha。
- 家族状态只供`factor-family-return-combination-v1.0.0-2026-08-29`研究。原始37项因子、候选连续值及历史状态全部保留；家族命中不得写回旧事件或生产注册表。
- 家族组合V1已完成：`support_location+controlled_pullback`是样本充足的历史20日扣成本收益冠军，但BH校正失败且已见2025明显落后共同门票。因此它只保留为人工观察标签，生产权重为0；四个职责家族均不新增正式因子、不改变37项注册表，也不写入当前评分。

## 周期规则

- 完整月线负责长期方向、支撑与反转。
- 完整周线负责中期趋势、波段支撑与反弹力量。
- 完整日线负责触发、位置与入场择时。
- 同一机器定义扩展到新周期时必须拥有独立 ID 和明确收盘规则。

## 父子依赖

- 底部 Doji、双底、更高低点和底部类吞没依赖客观支撑背景；没有支撑时不独立成立。
- 支撑可来自当时已知的 Volume Profile、K 线聚集或已批准的其他结构。
- “看涨吞没后下一根阳线”的 K 线跟随只作为吞没附加确认，不独立触发。
- 支撑位看涨吞没覆盖原“底部看涨吞没”，不保留两个重复概念。
- 独立 Bullish FVG 被扫至约 50% 后守住，可作为独立多头力量假设，需精确定义后实验。

## 重复证据

- 同周期同家族只保留最高贡献；双吞没取代单次吞没。
- 同周期 EMA20/50/200 可全部记录，但 EMA 支撑家族只贡献一次。
- 跨周期一致可登记共振，但是否加奖金由评分实验决定并封顶。
- 三推是最低结构门槛；低点结构仍有效时，可登记 4 推、5 推强度，具体优势必须回测。

## 新增底部与突破回踩结构（research-only）

- `structure.triple_bottom_pullback`（三底回调位置）：最近120个完整交易日内出现三个已经由右侧2根K线确认的摆动低点；相邻低点相隔5—60个交易日；三个低点的最大价差不超过“中位低点的3%”与“第三底确认时ATR14的1倍”两者中较大者；第一／第二底之间及第二／第三底之间都必须至少反弹1个ATR14；第三底确认时收盘不得比三底下沿低超过0.5个ATR14。它依赖长期趋势资格与60日回调，第三底确认日起观察10个交易日，属于`pullback_location`回调位置冗余组。
- `structure.double_bottom_neckline_retest`（W底突破后颈线回踩）：先由两个已确认摆动低点形成客观W底，再由完整日K实体收盘突破两底之间的颈线；突破后的10个完整交易日内，价格触及颈线的`max(2%, 0.5 ATR14)`容差带，最低价没有跌穿容差下沿且收盘位于颈线之上时成立。它必须依赖`structure.double_bottom`，并与`structure.trendline_three_push_retest`同属突破回踩家族，两个同时命中也只保留一次家族证据。
- 两项只使用信号时已经完成的日K；三底必须等第三底右侧确认，W底回踩必须等当天完整收盘。两项初始状态均为`testing`、`display_only`、正式及影子权重0，不进入当前排名、通知、止损或退出。
- 历史研究仍以长期趋势资格＋完整日线MACD刚金叉为共同门票。必须分别比较命中／未命中、共同门票、父因子及同家族旧因子；三底不得因为比双底多一个低点就默认更强，W底回踩也不得把父形态与子确认重复加分。

## 新登记的背离与退出因子假设

以下先进入规则与预登记，尚未升级为生产执行：

- `exit.structure.bearish_engulfing`：前一根完整日 K 收阳，当前完整日 K 收阴；当前阴线实体上沿不低于前一根阳线实体上沿，实体下沿不高于前一根阳线实体下沿。只比较实体，不要求影线吞没。
- `exit.structure.bearish_follow_through`：看跌吞没后的下一根完整日 K 继续收阴，且收盘低于吞没 K 的收盘；必须依赖前一日看跌吞没，不能独立成立。
- `exit.rsi.triple_bearish_divergence`：三个已确认价格波峰依次创新高，第一峰 RSI 处于预登记超买区，第二、第三峰 RSI 依次未创新高。信号只能在第三个波峰经过右侧 K 线确认后成立。
- `exit.macd.positive_histogram_weakening`：日线 MACD 柱仍大于零，但连续两个完整交易日缩短；这是弱动能证据，不能单独取代价格止损。
- `rsi.triple_bullish_divergence`：三个已确认价格波谷依次创新低，而相应 RSI 低点依次不再创新低。它是入场端普通 RSI 底背离的加强版，与两段底背离同属 `rsi_reversal` 冗余组；命中时取更强等级，不与普通底背离重复相加。

三峰 / 三谷背离中的波峰波谷必须使用已确认 pivot，保存每个 pivot 的日期、价格、RSI 和确认日，禁止用未来 K 线提前标记。

## 赢家／输家反向发现候选（research-only）

- 允许从日线MACD刚金叉事件的开发期最大赢家与输家中发现尚未登记的连续特征，但发现结果先属于实验特征，不得直接写入生产注册表。
- 第一批连续特征家族冻结为：均线排列与斜率、信号前5/20/60日动量、60日区间位置与回撤、EMA距离、RSI、MACD柱强度与变化、20日相对量、5/20日量能比、ATR与已实现波动、信号K线收盘位置与实体、信号日跳空。
- 每个新候选必须保存数值方向、由开发期冻结的分位阈值、家族、计算窗口和当时可得字段；同一家族最多一个候选进入权重挑战者。
- 最大100赢家／输家只产生线索；只有在全部前后10%和开发期内部校准中保持同向的候选，才可进入评分实验。
- 大盘和行业不是技术因子。大盘特征独立输出；没有当时行业成员快照的历史事件，行业特征记为不可用，不准以当前分类回填。
- V1完成后，新连续特征仍全部停留在研究层：高ATR、MACD柱加速、长期均线斜率和均线距离在最大赢家中明显，但不具备跨期稳定的单向胜率含义，统一归为“尾部弹性线索”，不登记为正式正向因子。
- 接近归零、代码变更、退市及公司行动异常必须带审计标记；在标记完成前，极端100只负责定性复核，不负责决定因子方向。

## 长期趋势内回调候选

- 下一轮候选总表以 `docs/PULLBACK_FACTOR_RESEARCH_ZH.md` 为准，研究顺序固定为“趋势健康 → 回调深度／时间 → 回调质量 → 重新转强”。
- ATR14占价格只作为波动、止损和仓位标准化工具，方向权重为0；不得把高ATR解释成上涨幅度或买入优势。
- 日线MACD柱三日增强属于回调后重新转强候选，必须依赖长期趋势和回调背景；在独立验证前只保存数值，不获得正式权重。
- 重点新增线索为回调持续时间、回调深度占前一上涨段比例、回调量能收缩、上下跌日量比、相对强弱保持、RSI中性区重回50和MACD金叉质量。
- 已被赢家／输家V1整体验证否决的临时方向不拆开上线；旧单因子不好用不等于其原始数值无用，可以作为组合中的条件，但必须重新预登记。

## 外部候选因子实验室 V2（research-only）

- 外部候选机器权威为 `research/factor-candidates-v2.json`；当前登记因子库含39项，其中本轮新增三底和W颈线回踩仍为0权重研究观察。外部候选目录不得被每日评分器自动读取。
- 首批来源只采用有可复核公式和实现的 Microsoft Qlib Alpha158、QuantConnect Lean Indicators 与 `ta`。外部项目只提供计算思想；是否适合 Sage Vista 必须由本项目事件池重新验证。
- 首批研究家族固定为：趋势效率、回归趋势质量、回调年龄、下行伤害、抛压/吸筹、短期修复、噪音环境和趋势重新掌控。
- 首批候选包括：Kaufman趋势效率、60日回归R²与末端残差、距60日高点交易日数、20日Ulcer Index、20日涨跌幅力量平衡、20日价格变化与量能变化相关、20日Chaikin Money Flow、Connors RSI、14日Choppiness、20日Squeeze释放，以及ADX与`+DI/−DI`合成的方向控制力。
- KER与回归R²同属趋势质量；价量相关与CMF同属资金/抛压；Choppiness与Squeeze同属噪音/收缩；ADX与DI差同属趋势控制。同一家族最多一个候选进入权重挑战者，其他原始字段仍保留。
- QQQ/SPY相对强弱和行业ETF相对强弱属于独立上下文，不得混入技术因子有效性的主检验；缺少历史时点行业成员时继续记为不可用。
- 最大单笔赢家只输出案例卡。因子方向必须由配对赢家/失败样本、全体命中/未命中、年度与走步窗口共同决定。
- 新候选初始`production_weight=0`、状态`research_candidate`；只有完整实验通过并获得另行批准后，才进入生产注册表和新评分版本。
- V2历史运行已完成：12个新候选没有任何一项通过预登记的配对、走步、样本、成本和BH联合门槛；不得因单一时期或最大赢家案例擅自加分。
- V2最初生成Connors RSI低尾、Choppiness高尾和Squeeze高尾三项后验假设；配对四组跟进已取消Connors RSI正向候选，仅保留Choppiness权重0观察与Squeeze比率`>=1.6751`风险扣分影子候选`-1`。所有`production_weight`继续为0，2025/2026不得再称为独立验证。
- Choppiness后续不再只看单点高低。实验候选`regime.choppiness_release_14_5`定义为14日Choppiness当前值减去5个交易日前的值；当前值至少`58.814226`且变化不高于`-3.0`时称为“高位下降／震荡释放”。同样高位但变化至少`+3.0`称为“高位上升”，中间为“高位横盘”；3日变化只作敏感度。
- `regime.choppiness_release_14_5`在机制实验完成前不是生产注册因子。只有下降／释放相对高位未释放在完整配对、跨期方向、样本、成本和BH门槛均通过时，才进入研究候选目录且权重仍为0；否则保留为不成立或样本不足记录，不得因为名称听起来合理而加分。
- 机制实验已经否决`regime.choppiness_release_14_5`：高位下降／释放相对高位未释放在开发、已见2025、已见2026的20日去极值增量分别为`-0.80/-3.00/-1.17`个百分点，处理样本仅`148/25/24`，所以不新增这项因子。
- 高位且5日Choppiness继续上升相对中低位在三段的20日去极值增量为`+0.48/+1.81/+0.87`个百分点，PF增量为`+0.151/+0.575/+0.289`，但配对BH均未通过；它只作为现有`regime.choppiness_14`下的零权重前向观察条件，不另立生产因子或新分值。
