# 自选股怎样登记与看结果

先登记，再等下一交易日成交；登记后不能改价或删单。这里只记录你的选择，不改冻结3W或模拟账户。

**当前：本地实现，待Claude核查；Actions建议补丁尚未接入。真实自选股记录为0笔。**

在仓库根目录运行（以下代码和价格只是命令格式示例，不代表建议交易）：

```sh
# 下一交易日开盘市价；止损、目标、理由必填
python3 -m research.lab.own_picks add SYMBOL --stop 90 --target 130 --why "登记理由"
# 限价单：可在登记时缩短挂单期限，默认40个交易日；26周=130个交易日
python3 -m research.lab.own_picks add SYMBOL --stop 90 --target 130 --limit 98 --wait 10 --weeks 26 --why "登记理由"
# 只撤销尚未成交的等待单；原记录保留，另外追加撤单事件
python3 -m research.lab.own_picks cancel ID
# 在冻结前向运行更新完本地缓存后，机械重算并旁列3W
python3 -m research.lab.own_picks compute
```

- 登记会返回ID，追加到 `research/lab/own_picks/picks.jsonl`。没有编辑/删除命令；重复撤单拒绝。日志加文件锁，避免并发覆盖；这不能防止人在程序之外篡改文件。
- 登记读取冻结前向同源本地数据及bulk缓存，不下载、不连数据库。参考日必须有最新已完成收盘；首个可成交交易日开盘后拒绝登记。正常交易时段不接受回填，收盘后才可登记下一交易日。日历复用现有常规美股假日表；早收市日保守等到纽约16:00，未知临时休市不猜测。
- 只支持五个冻结美股数据源里的代码，重复代码按前向配置顺序选择第一个来源。市价单以参考收盘设置m和目标R；限价单按限价设置。实际净R使用实际成交价到原止损的风险距离，扣每边0.1%。市价开盘已越止损时按开盘即退出，实际风险非正则净R标为不可计分，仍保留该笔及检查点计数。
- 参考收盘、最后已完成周ATR、m、目标R、类型、wait和hold登记后固定。孪生等compute时才按冻结股票池和ID种子抽30只（池不足不补抽），各自订单参数仅用登记参考日及以前的数据。次日行情未到显示“等待次日行情”。孪生沿用止损/历史覆盖不足的跳过规则，逐只留痕；不因结果重抽。
- 限价成交和成交前撤单直接复用冻结引擎；市价单下个交易日开盘成交。同一日止损与目标都触及按止损；跳空用开盘价。持有期限从成交日计第1日，weeks×5；缺行情停止，不补价、不把缺失当零收益。撤单不退出已经成交的持仓。

`compute`生成同目录 `outcomes.json` 和 `outcomes.md`，显示笔数、胜率、盈亏比、profit factor、平均净R、对随机孪生的差值与t，以及等待/撤单/持仓数。3W单独并列，两组累计起点可能不同，不把旁列表当配对比较。

**何时能说有效？** 复用Task036按退出日期/ID排序的前k笔检查点：30、60、100，之后每100笔；一次跨过多个检查点也逐一判。自选股≥100笔且对随机t≥2才写“有效”；30笔起若差值均值<0且t≤−2提醒owner。缺对照超过10%暂停该检查点判断；检查点之间只描述并保留最近检查点结论。此项没有Task036的模拟账户Sharpe条件，按038卡判定。

训练眼光另用 `research.lab.eye_judge` 读取私有答案副本与键；daily1/mixed1按作答顺序满十题揭晓，hk1最后4题须全部34题答完。只有三库合计≥100题才判眼光；每库和mixed1周期分格只描述。前向盲判B用冻结1.9合格已结束交易的Task036检查点，t为盲判“做”组净R减孪生净R；迟于成交开盘或缺成交时间证据的答案不计作盲判。

**局限：** 样本小；先看3W信号再挑选会影响独立性；只登记部分想法会造成选择偏差；交易相关、反复检查和三库构成差异可能使结论误导。训练结果不用于修改3W规则。
