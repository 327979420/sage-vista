# Northstar 产品决策日志

本文件记录产品方向与用户要求。实验数字和因子结论仍以 `research/experiments.jsonl` 为机器账本。

## 2026-08-25：产品收敛与统一因子库

- 主导航最终只保留总览、MACD Tracker、多因子雷达、MACD 研究。
- 双指标确认、RSI、成交量等独立页面计划移除，但 RSI、RSI 底背离、成交量突然放大等后台能力必须保留。
- 长期方向是建设约 20 个或更多因子的统一因子库，而不是长期使用固定六因子评分。
- 多因子雷达未来读取因子库，区分正式验证分、观察分和风险扣分，并避免同类证据重复加分。
- 所有新因子继续执行长期历史、独立验证与前向观察；失败实验永久保留。
- MACD Tracker 与多因子雷达必须在美国市场完整收盘后统一更新，检查日期一致、历史连续、无未来数据，测试通过才发布。
- 未来增加 Discord Bot，只有达到动态门槛的稀有机会才播报；先发布网站，再发送带详情链接的消息。
- UI 后续进行专业化改造：建设统一功能介绍页，集中放使用方法和解释；各功能页减少散落的 tips、重复说明和长篇文字。
- 页面瘦身不等于删除可复用的因子检测代码，任何删除前必须先做依赖审计。

- 建立版本化统一因子注册表，首批登记25个资格、趋势、MACD、支撑、价格结构、RSI、量能和风险因子。

- 多因子雷达输出开始区分正式分、观察分、风险扣分、分类得分、重要未命中、风险和注册表版本。
- 雷达页面同步显示上述解释结构；旧 `score` 与 `components` 字段继续保留，避免每日更新和既有页面中断。

## 2026-08-25：日终数据新鲜度改为失败关闭

- SPY 的小型 EOD 查询作为“数据源最新完整美国交易日”的权威日期；MACD、雷达和批量文件必须精确命中同一天。
- 批量接口未就绪、超时或日期不符时禁止静默回退，不替换公开结果，也不部署网站。
- 网站所有保留功能页统一读取 `update-status.json`，显示最新完整收盘日、同步状态及最后成功更新时间。
- 自动任务改为墨尔本工作日 10:15、11:15、12:15 三次收盘后检查；已是最新则安静退出，最后一次仍滞后则明确失败。
- 更新命令统一为 `python3 -m services.scanner.daily_tracker_update`；先生成临时结果，日期与防前视审计全部通过后才原子替换 MACD、雷达和状态文件。
