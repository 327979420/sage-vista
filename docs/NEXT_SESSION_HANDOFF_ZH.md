# 接手入口

从根目录 [AGENTS.md](../AGENTS.md) 开始；执行流程只维护在 [治理规则](rules/01_GOVERNANCE.md)。

- 当前状态：[CURRENT_STATUS_ZH.md](CURRENT_STATUS_ZH.md) 及其机器来源。核对实际工作目录，不依赖旧聊天或其他分支的日期。
- 按任务定位：[模块索引](rules/README.md)，必要时查 [代码地图](CODEBASE_MAP_ZH.md)。
- 当前任务：[CHANGE_REQUESTS_ZH.md](CHANGE_REQUESTS_ZH.md) 对应条目。业务语义变化先更新需求账本和对应规则文字，再改代码；已授权工作不重复申请。

排行榜是唯一权威顺序；完整保护要求见治理规则。本页不复制版本、断点、历史提示词或第二套接手清单。
