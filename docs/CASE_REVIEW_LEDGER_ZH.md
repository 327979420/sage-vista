## 一、案例账怎样使用

每个案例分开保存五种事实：

1. **机器原记录**：事件日、分数、因子、入场和结果，必须能够回到机器产物核验。
2. **用户人工观察**：用户看 K 线时指出的结构、强弱和风险。
3. **机器与人工差异**：机器漏了什么、错在哪里，不能事后把人工意见冒充机器原能力。
4. **候选假设**：值得做全样本实验的机制。
5. **状态**：教学、风险反例、待核验、待实验或已验证。没有全样本证据时不得写“有效”。

以后每轮回测至少新增：赢家、输家和边界／漏检案例，并保留人工意见。

## 三、BABA：用户最喜欢形态教学

### 人工观察

- 长期走势本身未必处于传统的持续上涨，但日线先出现了一段明确转强和上涨。
- 上涨后出现回调，用户记忆中最深位置接近 `0.618` Golden Pocket。
- 价格沿 EMA200 附近形成双底，EMA200承担长期动态承接。
- 下降趋势线形成三推，第三推完成突破。
- 第二个底附近出现日线 MACD 金叉。
- EMA20重新站上EMA50，日线均线恢复多头排列。
- 用户的交易思路是在趋势线突破时进入，第一目标看此前高点。

### 用户交易地图

这张图的重点不是“看到MACD金叉就买”，而是条件按顺序成立：

1. 日线先有一段明显上涨，证明短期趋势已经发生过真实转强；
2. 随后的回调最深接近0.618 Golden Pocket，并由EMA200附近承接；
3. EMA200附近形成两次相近低点，第二底时MACD同步金叉；
4. 下降趋势线经过三次推动后由完整日K突破；
5. EMA20重新站上EMA50，说明日线均线由修复走向多头排列；
6. 用户在趋势线突破附近考虑入场，把突破前的前高作为第一止盈／自然目标，而不是无限期持有；
7. 后续大幅上涨是案例结果，只能说明这张图值得教学，不能反过来用于调阈值。

案例中的具体日期、突破价、支撑价、止损和前高目标尚未由统一复权行情冻结。在机器重放完成前，任何精确数字都不得补写。

### 这个案例教什么

它不是要求所有股票先有多年长期上涨，而是说明：

```text
先出现可解释的日线转强
→ 回调到关键位置
→ 双底／三底承接
→ 趋势线突破
→ MACD与EMA确认重新启动
```

也不是要求所有机会必须同时复制Golden Pocket、EMA200、双底、三推、MACD和EMA排列的同一外观。BABA负责定义用户怎样阅读“先转强、再回调、获得承接、重新启动”这条因果链；具体候选可以由不同但已经登记的证据完成同一职责。

### 机器与人工差异

仓库此前只把BABA列成形态语言教学，没有保存用户完整的进场、目标和各条件发生顺序。本次只按用户叙述补齐机制；具体价格、事件日和0.618计算仍需从当时复权行情逐项核验。

### 候选实验

- 长期弱势但日线完成客观趋势转变，是否可以替代传统长期上涨背景；
- EMA200双底＋Golden Pocket＋三推突破是否比任一单项更好；
- 趋势线突破入场与颈线／前高目标的真实风险收益分布。

这些数字是已看过案例描述，不是独立有效性证明。

### 这个案例教什么

一个结构确认可能只是趋势转变；经过真实回调、动能重置和新pivot后再次启动，含义可能不同。机器必须区分：

- 第一次转变；
- 真实重置；
- 第二次重新加速；
- EMA正在改善；
- EMA已经完整多头排列。

### 机器与人工差异

当前个人形态V2可以保存“第一段三推＋真实重置＋第二段颈线突破／MACD／EMA转强”，但不会再次运行并保存第二套独立三推几何；当前多因子也只能登记一次`structure.trendline_three_push`。因此机器会把ADBE后半段写成普通二次启动，却不能明确回答05月的新三组下降高点、第二条趋势线及其独立突破日。这是本案例确认的真实能力缺口，不得事后把人工观察冒充旧机器已经识别。

### 已登记的新需求

- 需求ID：`CR-2026-08-30-033`。
- 候选因子：`structure.second_independent_three_push_confirmation`（二次独立三推确认）。
- 归类：复杂多因子的`price_structure／reacceleration`职责，与现有三推使用同一家族和同一颜色；不是新家族，也不把“我最喜欢形态”从4/4改成5/5。

- 计数：同一事件保留两项原始证据、一个家族覆盖和一次父子确认；仍只建立一笔模拟交易。
- 当前状态：已完整记录并暂缓；先重整总体架构，进入“复杂多因子检测／因子库重建”阶段时必须提醒用户重新审查。尚未进入生产因子库、检测器、排行、网站或Discord。

## 十、案例升级规则

- 一个案例只能提出假设或校正解释。
- 多个独立股票／时期反复出现同一机制，才能预登记新实验。
- 实验必须同时交付帮助、伤害和边界案例。
- 用户人工认可不等于统计有效；统计有效也不等于自动进入生产。
- 任何生产升级必须创建新的规则／评分／执行版本，并保留旧案例原貌。
