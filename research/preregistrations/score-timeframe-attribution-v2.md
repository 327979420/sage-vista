# 完整事件池评分、周期与因子归因 V2｜预登记

实验 ID：`score-timeframe-attribution-v2.0.0-2026-08-29`
状态：`completed_research_only`
生产影响：无；不改门票、正式评分、排行、止损、退出或通知

## 研究问题

在完整日线 MACD 刚金叉的全部历史候选中，现行技术分是否具有单调性；赢家和高收益样本相对同池基础出现率富集哪些因子；哪些单因子与少量预先冻结的跨家族两因子组合能在开发期、2025独立验证和2026前向期保持同向增量；完整周线和月线证据是否对应更合适的持有窗口。

## 数据冻结

- 复用 `macd-factor-history-v2.0.0-2026-08-29` 的自然周 Unified V2 候选池和 GitHub Actions 历史价格缓存，不重扫或重新下载已有行情。
- 2000只作指标预热；2001—2024开发；2025独立验证；2026前向观察。
- 门票为信号日完整日线 MACD 从不高于信号线变为高于；所有选择只读取当时或更早数据。
- 完整周 / 月只使用信号日之前已经结束的自然周 / 月。完整周线刚金叉与周线柱改善分开；月线刚金叉沿用已登记因子并做缓存复算审计。
- 技术因子是主实验。市场、行业及其调整分不进入技术分、单调性或因子有效性的证明。

## 结果与比较

- 下一交易日复权开盘进入；固定持有 `5/10/15/20/40/60/100/120` 个交易日。
- 单因子和两因子晋级的冻结主窗口为20个交易日；其余窗口用于周期匹配和稳健性，不从中事后挑一个最好看的窗口替代主检验。
- 当前技术分、周期等权分和预登记 V3（日1.0、完整周1.5、完整月2.0）在同一事件池对照。完整周线刚金叉只作为单因子，不事后改写V3。
- 每个交易日对候选技术分使用中位秩五分组，避免大量同分造成假阶梯；同时保留每个原始分值。报告各组样本、胜率、中位数、1%去极值均值、PF、期望、20/50bps成本及秩相关。
- 赢家：对应原始固定持有收益 `>0`。高收益：同一时期与窗口前10%，另报绝对 `>=10%`。失败：收益 `<=0`。
- 每个因子报告在全部候选、赢家、高收益、绝对高收益和失败样本中的出现率，以及命中对未命中的增量。父条件和冗余关系按当时注册表执行。

## 独立性与统计护栏

- 主分析每只股票在最长120个交易日窗口内保留首个事件；全事件仅作敏感度。
- 单因子开发 / 2025最低命中样本为300 / 100；两因子为200 / 75。2026不足时只标方向观察。
- 单因子开发期多重比较使用 Benjamini–Hochberg；不得用2025或2026选择因子、阈值或组合。
- 冻结组合仅限长期研究B级且跨家族：`volume.bottom_expansion + structure.bottom_bullish_engulfing`、`volume.bottom_expansion + risk.overhead_unfilled_gap`、`structure.bottom_bullish_engulfing + risk.overhead_unfilled_gap`。组合必须同时优于总体和两个单因子，否则不成立。
- 极端值不能靠均值推动结论；以中位数、1%去极值、PF、时期方向和成本敏感度共同判断。
- 若缓存缺失、窗口未成熟或公司行动异常，明确计数并排除对应窗口，不以年度聚合数补造逐事件结果。

## 留档与发布

- 每个自然周保存版本化压缩事件检查点；每个自然年保存覆盖、成熟度、数据指纹和紧凑汇总；失败与中断同样留档。
- 第一阶段只研究原始持有收益。固定支撑止损、+1R后最高收盘下8%追踪，以及主动退出在各自实验中另行对照。
- 全期完成前网站不发布临时最优因子；完成后仅发布总体、五年段、2025、2026、因子层级、推荐持有窗和明确限制，逐周明细留在GitHub档案。

## 判定

有效因子必须在开发、2025和2026保持同向稳健收益增量，满足冻结样本与BH要求，20/50bps后仍为正，且不依赖极端值。未满足者只能标为候选、样本不足、不稳定或不成立；本实验结果不会自动改变生产权重。

## 完成结论

- 审计后保留62,170个事件，主去重样本13,296个；1,615个早年事件因缺少逐事件价格连接而排除，32个无法复现精确门票的旧事件排除。
- 20日共同门票在开发 / 2025 / 2026 的胜率为54.39% / 50.98% / 54.29%，PF为1.228 / 1.356 / 1.513，扣50bps期望为0.30% / 0.88% / 1.60%。这是原始持有事件证据，不是组合收益承诺。
- 现行历史分、周期等权与V3均未形成跨三段单调排名；31个附加因子没有一个达到有效标准，三个冻结组合均未通过样本与严格增量条件。
- 完整周线金叉样本严重不足；完整月线金叉在开发和2025的长窗较强，但2026长窗成熟样本仅39 / 26 / 17且相对增量不稳定。
- 不改变生产权重。相对放量与回撤只保留为高收益尾部标签；止损、移动止损与主动退出继续由独立实验判断。
