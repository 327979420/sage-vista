# 等月线的日线确认，放进账户后怎么样？

**这次B更好，但还不能采用为正式规则：多赚约1.09万美元，回撤只小幅下降，而且优势主要来自最近一个历史阶段。**

A是直接入场；B只让月线机会等待日线支撑反转。两组都从10万美元开始，其他规则、费用和行情相同。使用2005—2025年保存的977个机会，账户结算到2026-09-11；没有重新选股。

## 先看账户

| 指标 | A：直接入场 | B：月线等确认 |
| --- | --- | --- |
| 最后多少钱 | $148,036.72 | $158,962.95 |
| 全期间总收益 | 48.04% | 58.96% |
| 年化收益 | 1.89% | 2.24% |
| 从高点最多跌过 | 23.99% | 23.16% |
| 实际买入 | 837笔 | 825笔 |
| 平均资金投入股票 | 24.10% | 23.33% |
| 平均现金余额 | $101,558.72 | $104,127.98 |

这是约21年的结果，不是一年的收益。两组整体年化收益仍低，平均只有约四分之一资金在股票里；不能把“B比A好”理解成“策略已经很好”。

## 多出来的钱从哪来？

| 来源 | B比A多/少赚 |
| --- | --- |
| 两边都买的67笔月线交易 | 少$7,432.54 |
| B没买的21笔月线：避开18笔亏损，也错过3笔盈利 | 多$10,340.57 |
| 只有B买成的4笔月线 | 多$5,372.34 |
| 日线、周线因现金和名额变化，新增与失去交易的净影响 | 多$2,645.86 |
| **合计** | **多$10,926.23** |

**不能说等待普遍带来了更好的买点。**两边都买的67笔，B总体少赚；其中40笔买得更贵，26笔更便宜，1笔相同。避亏也不全是日线确认的功劳：A买了而B没买的21笔里，14笔是等到确认时已经不符合原止损计划，被原有风控拒绝。

资金路径确实有影响：B多买成20笔日周交易，合计盈利$8,313.62；但也少买了另外15笔，放弃A的盈利$5,667.77，净贡献才是$2,645.86。20笔里有8笔能对应当时正在等待的月线，其余是此前资金变化的后续影响。

## 等待的代价

100个月线机会中，A实际买入88笔；B有98次确认，但最后只买入71笔。买成者等待中位20个交易日。其余29次中：2次结构失效、15次不符合旧止损计划、11次满仓、1次现金不足；没有因等满12个月而到期的案例。

84个有可核对前高的机会里，5个在确认前已经摸到前高。完整逐笔资料记录了那些等待时涨走的股票。

## 哪些结论能用？

- **能确认：**这次两组账务对得上，净值差额的来源也全部对上；原18股V0基准没有改变。
- **这份样本支持：**等待能通过避开部分交易、改变资金使用，让账户结果改善。
- **还不能证明：**未来也有效。约89%的净优势来自2020—2025年；2010—2014、2015—2019两段，B的新增盈亏反而略差。这批历史已被看过，没有独立留样；也不是完整市场榜单回测。

**判定：KEEP AS CHALLENGER / NEED MORE DATA。**

保留这条等待规则继续验证，不替换正式baseline。下一阶段应看独立样本或之后新出现的机会，检验避亏和资金使用的改善能否重复；不要据此继续调参。
